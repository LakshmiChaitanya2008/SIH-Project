# SamadhanSetu

## Objective
Convert citizen-submitted problems into validated innovation challenges.

## Core pipeline
Submission
→ AI Understanding
→ Structured Issue
→ Embedding
→ Similarity
→ Clustering
→ Emerging Problem
→ Admin Validation
→ Innovation Challenge

## Engineering principles
- Prefer simple solutions.
- Do not overengineer.
- Reuse existing components.
- Do not rewrite working frontend.
- Keep AI providers replaceable.
- Keep APIs strongly typed.
- Every feature must be testable.
- Do not modify unrelated files.

## Frontend
- Preserve existing UX4G design.
- Maintain Indian government portal visual language.

## Priority
1. End-to-end functionality
2. Demo reliability
3. Correctness
4. UI polish
